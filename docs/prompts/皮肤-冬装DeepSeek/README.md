# 皮肤：冬装 DeepSeek（约 37 张）

DeepSeek 的另一套衣服。冬天裹得严严实实的鲸鱼：怕冷、想吃热乎乎的白饭，嘴上喊冷其实玩得很开心。立绘和其他角色一样按 CC BY-NC-SA 4.0 授权。

做好后在右键菜单 / 「设置…」里给 DeepSeek 换衣服；也可以在「设置… → 额度」的「峰谷换装」里让她到点自己换。台词、动作逻辑和原版一样，只换立绘（台词我导入时按这套衣服的味道补）。

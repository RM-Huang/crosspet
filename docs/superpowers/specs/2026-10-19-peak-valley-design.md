# 峰谷时段：额度栏时间条 + 按时段换衣服 · 设计

日期：2026-10-19　状态：loki 已口头确认要点，待审阅本文
来源：loki 的想法（10-19），配套他在 `docs/prompts/皮肤-峰谷DeepSeek/` 构思的「高峰上班 / 空闲回海里」皮肤

## 为什么做

DeepSeek 的 API 分高峰 / 空闲两档价（空闲半价），GLM 编程套餐也分（非高峰积分减半）。用的人想知道「现在贵不贵、几点变」。顺便让她跟着时段换衣服：高峰穿工作服，空闲换休闲装——桌宠本来就是陪你干活的，时段一变她就换身衣服，比看价目表直观。

## 目标

- 额度栏里一条「一天的时间条」：红 = 高峰，绿 = 空闲，一根线标出现在（loki 在三种样式里选的 B，草图见下）
- 设置里每个有峰谷的 AI 选「高峰穿什么」「空闲穿什么」；时段切换那一刻她演一下换装、说一句话
- 时段里你手动换了衣服，这一段听你的；下次时段切换再按规则换（loki 定）
- 规则写在网页层、每家一份，以后别家出峰谷价只加一条规则
- 判断写在网页层，外壳只存设置、执行「换衣服」（`docs/架构.md`）

不做：
- **法定节假日**（loki 定：先不做，周末做好就行）。代价：节假日落在工作日时，DeepSeek 的时间条照样画高峰、衣服也按高峰换。设置页说明里写一句「法定节假日暂不识别」
- 在额度栏写价格数字、算省了多少钱
- 新立绘：换装动作用特效做，不为每套皮肤另画

## 一、各家规则（北京时间，和电脑的时区无关）

| AI（角色 id） | 高峰 | 其余 | 来源 |
|---|---|---|---|
| DeepSeek（`deepseek`） | 周一至周五 9:00–12:00、14:00–18:00 | 空闲，价格减半；周末全天空闲 | [定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 注 (2)，10-19 查 |
| GLM（`glm`） | 周一至周五 14:00–18:00 | 非高峰，积分按 50% 扣；周末全天非高峰 | [套餐概览](https://docs.bigmodel.cn/cn/coding-plan/overview)「积分抵扣」，10-19 查（文档没提节假日） |

- 「周一至周五」按北京时间的星期几算。调休上班的周六不在周一至周五里，按字面规则算空闲（DeepSeek 原文就是这么写的）
- 时区：一律换算成 UTC+8 再判断，电脑设在别的时区也对
- 规则写成数据：`{ days: [1..5], peak: [['09:00','12:00'], ['14:00','18:00']] }`，区间左闭右开（12:00 整已经是空闲）

## 二、用户看到的

### ① 额度栏的时间条

草图（loki 选的 B）：`.superpowers/brainstorm/…/content/quota-peak.html`

```
 余额 ¥23.60
 ▕██████████▌▓▓▓▓▌██▌▓▓▓▓▓▓▌█████████▏   ▓ = 高峰（红） █ = 空闲（绿）  │ = 现在
  0        9   12  14     18        24
```

- 放在额度文字下面；当前角色有峰谷规则才出现（DeepSeek 和它的皮肤、GLM），别的角色不出现
- 额度文字是空的（没配余额查询）也照样显示时间条
- 周末整条绿色
- 刻度只标 0、24 和这家规则里的切换点（DeepSeek：0 9 12 14 18 24；GLM：0 14 18 24）
- 那根线每分钟挪一次
- 开了「合并显示各家额度」时：时间条放在表格最下面、横跨整张表（和 Codex 重置提醒那一行一样的位置），只画当前角色那家的
- 贴边缩起来、彩蛋里：和额度一起藏起来（现有规则）
- 设置开关「额度栏显示峰谷时段」放在「额度」页，**默认开**（我的决定：只影响有峰谷的两家，信息有用、不打扰）
- **不区分接口**（loki 定）：凡是显示成 DeepSeek / GLM 角色的都画时间条，包括第三方平台、中转、按量付费的 GLM 接口、国际版 z.ai——这些人的价格其实不分峰谷。开关旁写明「按 DeepSeek 官方 API 和 GLM 编程套餐的规则，其他渠道以各自价格为准」，不需要的可以关

### ② 设置：按时段穿什么

「额度」页（或角色页，见「留给实现的」）每个有峰谷的 AI 一组：

> **DeepSeek 峰谷换装**　高峰穿 [原版 ▾]　空闲穿 [原版 ▾]
> 时段：工作日 9–12、14–18 点高峰；周末全天空闲。法定节假日暂不识别

- 下拉选项 = 「不换」+ 原版 + 这个角色已有的皮肤（和右键菜单里那一组一样）；默认两个都是「不换」
- 「原版」是一件真的衣服：高峰穿卫衣、空闲穿原版 = 每天来回换（我的决定，审阅时提出：空字符串既像「原版」又像「不管」，所以单独加「不换」）
- 只设了一边（另一边「不换」）：只在进入设了的那个时段时换
- 这个角色没有皮肤（比如目前的 GLM）：这一组不出现，只有时间条
- 设置改了之后**不立刻换**，等下次时段切换（我的决定：和「这一段听你的」一致；想马上换就右键菜单手动换）。例外：刚设置的那一刻正好处在规则要求的时段而且衣服不符，也不动——避免「改设置 → 她突然换衣服」的惊吓

### ③ 时段切换那一刻

- 触发：时段从高峰变空闲、或空闲变高峰，并且那个时段设了要穿的衣服、和她现在穿的不一样
- 正在显示这个角色：她演换装（特效：一团烟 / 转一圈，约 1 秒，烟最浓的时候换上新衣服），然后说一句换装台词
- 没在显示这个角色：悄悄换好，不演、不说
- 她在忙（AI 在干活、等你回答、彩蛋、正在更新 / 道别、多会话）：衣服**先不换**，等她闲下来再演再说；闲下来时如果时段已经又变了，按最新的时段换
- 台词：皮肤自己的 `character.json` 的 `lines.peakStart`（进入高峰时）/ `lines.valleyStart`（进入空闲时），可以多句随机挑；没写就用 `LOCAL_LINES` 里的默认句（「高峰到了，换身衣服干活～」/「空闲时段，半价啦～」之类）。台词按**换上之后**那件衣服取

### ④ 「这一段听你的」

- 记住「最近一次按规则处理到的是哪一段」：`<角色>|<这一段开始的时刻>`（比如周五 18:00 到周一 9:00 是同一段空闲，半夜 0 点不算换段），存 localStorage（`crosspet-peak-applied`）（我的决定，审阅时提出：按日期分段会在半夜把你手动换的衣服换回去）
- 只在这个记号变了（进入新的一段）时按规则换；同一段里你手动换了，不会被换回去
- 重启桌宠：记号没变 → 不动（你手动换的那件保留；22:00 关机、第二天 8:00 开机还是同一段空闲，也不动）；变了（比如早上 10 点开机已经是高峰）→ 按规则换，**不演不说**（刚启动就换装演出有点吵——我的决定）
- localStorage 被清掉：当成进入新的一段，按规则换一次

## 三、程序分工

### 网页层 `app/web/peak-hours.js`（新，纯函数，node 测试）

- `RULES`：上面那张表
- `beijing(date)` → `{ day(0–6), minutes, ymd }`
- `periodAt(rule, date)` → `{ kind: 'peak' | 'valley', key, until }`（`key` 用于「这一段」；`until` 是这一段结束的时刻，跨天的空闲段到第二天第一个高峰为止）
- `segments(rule, date)` → 今天的色块列表（周末一整块绿），给时间条画
- `ticks(rule)` → 刻度
- `due(rule, date, appliedKey)` → 这一刻要不要按规则换

### `app/web/index.html`

- 每分钟（对齐到整分）检查一次：挪时间条的线；对每个有规则、设了衣服的角色看 `due`
- 要换且正在显示她、她闲着：演换装特效 → 特效中途 `toShell({ wear: { id, skin } })` → 外壳换好调 `refreshLook` → 说换装台词
- 要换但没在显示她：直接 `toShell({ wear })`，不演
- 要换但她在忙：挂起，`restPose` 回到闲着时再处理
- `setPeakSkins(map)`：外壳在网页加载完和设置变化时调，`map = { deepseek: { peak: 'deepseek-hoodie', valley: '' } }`；`''` = 原版，没有这个键 = 不换
- `setPeakBar(on)`：时间条开关
- `renderQuota()` 末尾挂时间条（两种排版都要）
- 开发者控制台「场景演练」加一项「峰谷换装」：用假时间演一次高峰 → 空闲，演完恢复

### `app/web/effects.js`

- 新特效 `changeOutfit`（烟 / 转圈），给出「换衣服的时机」回调

### 两个外壳

- 设置 `peakSkins`（字典，默认空）、`peakBar`（布尔，默认 true）；网页加载完、设置变化时调 `setPeakSkins` / `setPeakBar`
- 设置页把每个角色的皮肤列表交给网页（现在角色页已经有 `skins`，复用）
- 收到网页的 `{ wear: { id, skin } }`：调现有的 `wear(id, skin)`（Mac）/ `Wear(id, skin)`（Windows），不切换当前角色
- 反馈里加一段「峰谷换装 DeepSeek 高峰 xx / 空闲 xx」

### 设置页 `settings.html`

- 「额度」页：时间条开关 + 每个有规则、有皮肤的角色一组两个下拉（规则表从 `peak-hours.js` 读，不在设置页再写一份）

## 范围说明（我的决定）

- 这次只做功能，**不等峰谷皮肤的新立绘**：现在 DeepSeek 只有「Claude 卫衣」一套，功能先用它和原版验收；`docs/prompts/皮肤-峰谷DeepSeek/` 的高峰 / 空闲皮肤画好后作为普通皮肤加进来，自带 `peakStart` / `valleyStart` 台词即可，不用再改程序
